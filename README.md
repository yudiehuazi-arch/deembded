# RF De-embedding Workbench

基于用户现有 scikit-rf 去嵌引擎的简化网页工作台。核心流程：上传 Total、2X Thru A、2X Thru B，分别劈半提取左右 1X 夹具，再进行单端 S2P 或差分 S4P 去嵌。

## 启动

```bash
python -m pip install -r requirements.txt
python run_server.py
```

浏览器打开 `http://localhost:8000`。

## 输入

- `Total`: Fixture A + DUT + Fixture B 的测量网络。
- `2X Thru A`: A 侧背靠背校准标准件。
- `2X Thru B`: B 侧背靠背校准标准件。
- 支持 S2P / S4P Touchstone。三份文件必须端口数一致；频率网格可不同，服务端会取共同频段并在 Total 频点上插值。
- 差分 S4P 可选择自动检测、标准顺序或 PLTS 交叉端口映射。

## 网页功能

- 三份文件齐全后自动识别 S2P/S4P、共同频段，并在 A、Total、B 三列下分别显示端口映射关系。
- S4P 支持自动检测、标准顺序和 PLTS 交叉端口映射。
- 识别后的网络会复用到去嵌计算；结果曲线按需抽样转换混合模参数，Touchstone 导出只在点击下载时生成。
- 每个输入文件卡片下都可手动填写参数，也可点击快捷项添加/移除参数；默认提供单端或混合模常用项，并支持添加、删除自定义快捷项（保存在当前浏览器中）。
- A、Total、B 各自保留参数输入框，但共用一个“生成组合图表”按钮；按各自频率曲线插值到共同频段后，可把三个输入网络的参数叠加在同一张图中（每个文件最多 8 个参数）。去嵌结果图最多可叠加 8 个参数，并可对比 Total、DUT、1X 夹具和 2X Thru 网络。
- S4P 输入图下自动计算 2X Thru A/B 的 `SDD21 − SDD22 = 5 dB`、`SDD12 − SDD11 = 5 dB` 及两组 SDD 曲线相等的插值交点频率；输入图和去嵌结果图均支持光标竖线、曲线交点圆点及频率 / Y 值读数。
- 输入图和去嵌结果图均可手动设置 Y 轴最小 / 最大值（留空的边界自动缩放），并可输入 X 标记位置后固定标记线；频域图单位为 GHz，TDR 图单位为 ns。
- 输入网络图切换至 TDR 时，会将 2X Thru A、Total、2X Thru B 三条阶跃阻抗曲线对齐到共同频段后叠加；去嵌主结果图也可切换至多网络 TDR 对比。S2P 使用 S11/S22，S4P 使用所选映射下的 SDD11/SDD22；可调整 DC 外推、Hamming/Hann/Blackman/无窗、10–90% 上升时间、时间显示范围和绘图点数。默认使用线性低频外推、Hamming 窗和 0 ps（未额外平滑）。TDR 结果受带宽与外推/加窗设置影响，应视作频域数据的时域估算。

## 输出

- 去嵌 DUT Touchstone 文件。
- 从 2X Thru A、B 劈半得到的左/右 1X 夹具文件。
- 自定义 S 参数幅度对比图、无源性和互易性诊断。

为加快去嵌，已解析网络会在服务进程内存中临时缓存（最长 10 分钟），供后续计算复用；原始 Touchstone 不会作为项目文件长期保存，解析器使用的临时文件会在解析后删除，服务重启后内存缓存即清除。导出文件按需生成。质量指标是诊断信息，不代替工程验证。
